## 保留的后继范围

E6 与 MCP diagnostics 对应 B/D 可以按以上 AC 单独关闭；不代表全 Resource Catalog/RM、W4-B/W4-D 或 RFC294 完成。

- Resource Catalog / W9-B：`background:packages/backend/src/modules/resource-catalog/infrastructure/mcpDiagnosticsEffects.ts#$setInterval:96`、同文件 `#$setTimeout:92`。原 reconcile/deadline timer 的实例 lifecycle 保持，`managed=false`；未宣称接入全局 ManagedBackgroundRegistry。
- Runtime Management / 后继 driver 切换：本次只移动 eligibility owner 并注入诊断所需结果，不领取所有 driver/inventory 机制迁位信用。
- System Operations / W9-E：physical restore generation 不属于本项；现 provider pause/resume/drain 语义保留。

回滚复用同一持久化表，先按原 lifecycle drain/pause，随后切换 root 的唯一实例；不同时启动新旧 service，不清空 session/lease/event 数据。历史台账里的“待 T4/T5/T6”描述记录各批当时状态，当前实现范围以本页和最终托管证据为准。
