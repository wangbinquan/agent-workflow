# RFC-250 UX 审计移交：Intent 详情投影与 mutation 反馈

- 日期：2026-08-03
- 状态：Finding accepted by RFC-235 ownership；未新增实施批准
- 来源：RFC-250 全前端 UX 审计与独立设计门

## 当前源码 finding

- `packages/frontend/src/routes/intent.detail.tsx` 的 answers turn 仍直接序列化 JSON，未知 content 没有安全的
  业务降级投影。
- answers/retry/cancel/rebase/unmount 等 mutation 的 pending/error 没有统一渲染；只有 send message error
  明确进入当前 JSX 反馈面。
- archived / apply-in-flight 会话仍可能暴露当前后端必然拒绝的 rebase/unmount 等动作。

## 所有权

这些问题逐字属于 RFC-235 plan 的 T5.4/T5.5/T7：preceding-question 语义投影、unknown content 不输出 raw
JSON/controls、统一 canMutate/action pending/error 与 source-bound mutation。RFC-250 不修改 Intent
production，也不建立临时 projector、action gate 或 outcome contract。

RFC-235 后续设计/实施门必须把以下负向场景作为验收：known answers 可读、unknown payload 不倾倒、archived
无 mutation controls、每个 write 失败可见且 retry 使用 frozen identity、apply/session in-flight 不重复写。
