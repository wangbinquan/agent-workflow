# 观测页面字体统一（2026-10-13）

用户确认范围为 AW、CS 的全部观测页面。当前 AW 柱顶文字实际继承按钮的 16px 字号，超过同卡片 14px 的标题；日期、分类用量和说明又混用 11/12/14px，破坏阅读层级。

统一方式是继续使用现有字体 token、页面标题、Card、表格、控件与泳道组件，仅在观测入口启用字体范围。正文使用 `--font-md`，图表数值、日期、图例、分类用量和辅助说明使用 `--font-sm`。标题与摘要主数值继续沿用现有组件层级。柱顶数据使用普通文字颜色，焦点和点击交互继续复用按钮原语。

完整报告、旧报告回归入口和运行时人民币费率入口使用相同范围。柱顶完整 Token 数值不拆行；列宽随内容扩展，横向滚动继续由 TableViewport 提供，不截断原始数值，也不改统计人口或时间窗。CS 同步处理其观测图表、日期、泳道文字和资源历史 TimeSeries 文案；范围外的页面保持原字体。

回归用例使用实际趋势组件和生产样式，覆盖超过安全整数范围的完整 Token 字符串、100001 个任务、10000001 次执行、原时间窗点击导航、范围外控件字体不变，以及资源图表公共组件的独立调用方。用例编写完成后再集中核对，不本地执行 AW 功能测试。静态结果、正式页面验收和 exact-SHA CI 分开记录。

用户后续反馈重复展开采集说明降低信息密度。默认视图改为总量、四类 Token、人民币金额及数值旁一个简短的可展开缺口标记。复用公共 FormSection 并扩展 compact 变体，详情默认折叠，原采集数量、四类记录覆盖、历史引用覆盖、缺口原因和定价覆盖均保留。0 次登记调用时呈现原记录数量，不再把 0/0 显示成有效覆盖。原用量、缺口和人民币数值断言保留，增加真实 disclosure 的默认折叠、展开、收起和多行明细回归。
