# RFC-371 System 组与任务运行态计时

## 已确认的问题与处理范围

原记忆作业 `01M4F4A7DWADNT51VTQ86JZ3Z8` 的四次执行时长为 5985、8230、6948、61738ms，累计与活动并集均为 82901ms。组墙钟周期是 8291976ms，包含重试间隔。现有 System facts 把组起止差复制到 `runningMs`，又把未结束组的首次开始当作 `runningSince`，使“任务运行态历时”与墙钟混为一谈。

普通 Task 的 `runningMs/runningSince` 来自原执行状态历史，包括任务运行但 Agent 尚未活动的时间；System 组没有该状态历史。不能用 Agent 活动并集冒充普通任务运行态，也不能为 System 补造 Task 行或状态记录。本片修复这个已发现的错误；AW-R07 的等待分解、关键路径与执行对比仍开放。

## 事实与查询合同

- `ObservationTaskFacts.runningMs` 允许 `null`，表示原 owner 未提供任务运行态计时。System 查询的该字段和 `runningSince` 均为 `null`，删除墙钟替代公式；普通 Task 原字段与预算计时保持。
- 同一快照的完整尝试分页、真实起止时间、重试历史、墙钟、尝试累计及活动并集原算法保持。四次失败/成功及所有未知边界仍进入原统计，不因任务运行态不适用而删行。
- 完整单任务查询遇到 `runningMs=null` 时，`timing.runningMs` 也为 `null`。不能通过 JavaScript 的 `null + duration` 或 `BigInt(null)` 转成零。旧有界查询同步保留 nullable，不能在正式完整链路修好后留下错误的另一读面。
- 总览按所有选中任务到 EOF 统计运行态覆盖。只有每个任务都有有效原运行态时间时，`summary.timing.runningMs` 才是完整总量；任一缺失时为 `null`。
- 缺失时附加 `runningCoverage: { tasks, observedTasks }`，使用精确十进制字符串。若至少一个任务有原运行态证明，附加 `recordedRunningMs` 保留已记录小计；全未知不伪造小计零。完整普通任务响应保留旧形状，不添加冗余覆盖字段。墙钟分布与其原 `unknown` 分母不改成运行态覆盖。
- 两种终态（ready / 可查询 not-ready facts）采用同一时间类型和数值合同。选择维度、实际消耗窗口、任务树根均由原 builder 处理；任务运行态缺失不会改变 Token/CNY 完整性、任务人口或消耗窗口。
- 报告缓存族从 `scope-metrics/12` 推进到 `scope-metrics/13`；原封存报告保留原内容。新请求使用修正后的事实，不回写旧报告或任何执行/用量原记录。

## 正式呈现

System 单任务详情不展示没有原状态历史的“任务运行态历时”行；仍显示墙钟、每次起止/时长、尝试累计和活动并集。上述原作业应显示 8291976ms 墙钟及 82901ms 累计/并集，不能再次把前者放入执行时长。

跨任务总览的运行态不完整时，已有小计使用“已记录任务运行态历时”并附紧凑覆盖说明；没有任何原运行态证明时显示 `—` 和覆盖说明，不显示确认零。不创建新全局卡片，不改变总览专属卡片、Token 四桶/柱状图/人民币或非总览页结构。复用现有 detail-grid、muted 文案与中英文翻译，覆盖说明放在原值所在行。

旧报告缺少新字段时沿用原响应形状，不自行从 ID 前缀推断时间、补齐覆盖或重算旧封存数字。页签、查询范围、返回位置和焦点合同保持。

## 实施与验收

1. 独立功能设计门通过后，只改原 System facts、共享 nullable 时间合同、两条运行态计算读面、原总览汇总、原详情呈现与缓存键。无数据库迁移、新调度器或执行状态写入。
2. 双 provider 原组/owner 夹具追加有重试长间隔及并发重叠的对账，完整分页到 EOF；墙钟、每次时长、累计、并集、nullable 和原 Task 状态计时分别断言。原普通 Task 1001/10001 用例、旧断言及预算保持。
3. 追加混合任务、全未知、合法确认零、运行中 asOf 和未知尝试边界的覆盖/已记录小计回归；不把未知小计零或不完整活动区间提升为完整。
4. 追加中英文正式详情/总览显示回归，验证 System 详情无错误运行态行，混合范围保留已记录时间和覆盖；Token/CNY、原泳道/返回行为仍由原回归约束。
5. 源码独立实现门、确切候选格式/lint、原官方架构配套和新 exact-SHA hosted CI 分别验收。不运行本地 AW 产品测试、类型检查、构建、服务或压测。共享架构文件若存在并行输出，保留并按共享规则同步，不能用覆盖文件制造配套。
6. 用同一原记忆作业及定时任务重新构建观测报告，读取实际 EOF，与原 readonly owner 和原生计量核对，再看正式页面。只重建查询报告，不重跑模型、不改恢复完成的运行时配置。新报告 Token 四桶和冻结人民币分别保持 13335 / ¥0.037662 与 33589 / ¥0.041582。

此文档为修复设计与执行计划，不代签实现、CI、正式页面、CS 部署或两个 RFC 完成。
