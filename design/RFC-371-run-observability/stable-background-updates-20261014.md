# 静默后台版本更新

用户指出“正在重新统计”整行提示一直插入、撤下，导致页面跳动。该横幅删除，固定的统计截至时间继续表明当前快照；后台更新期间保留有效四类 Token、人民币、趋势与原 DOM。原报表事实失效仍立即撤回，不用旧数字掩盖失效。

另一个实际触发来自版本通知立即改变报表查询 key 和预设时间窗，连续提交会取消正在进行的读取。现在正式页面只订阅一次已提交投影版本；报表读取完成后才接纳当时最新版本，期间的通知合并成最新待处理版本，不取消当前读取，不推进它的 URL 时间端点。新版本准备完成后继续最新版本，使用已准备的投影，页面不显示额外“正在统计”横幅。用户显式切换范围或任务仍按新查询立即执行，可以取消旧范围；自定义范围与时间编辑中的毫秒端点保持。

汇总提前切换还会让趋势、任务表和 Agent 表短暂显示加载态。现在同一显示范围的后台替换会先读取当前已挂载主视图在新报告中的首页，核对报告 ID、节、父级、完整总数和游标，再发布新汇总；准备期间继续显示原报告及其原页面，禁止新汇总混用旧页面。用户打开的贡献弹窗仍绑定原快照，不纳入主视图替换。只准备正在显示的页，不遍历全量明细，不改变完整统计范围；未挂载准备页最多保留 60 秒。真实失效和错误仍按原规则撤下未验证事实。首次投影提交沿用原先等待中的报告句柄，不额外创建报告。

所有生产修改与用例先写齐，再集中验证。原四桶/CNY/截至时间、旧报告失效、任务与维度返回、焦点、准确分页和范围恢复预言保持；旧连续自动取消用例按新行为要求改为“自动更新不取消、完成后处理最新”。另补多版本突发只读取最新并保留同一卡片节点，以及用户显式切换周期仍取消旧范围。独立功能检视、相关用例、实际页面与新 SHA CI 分别记录，不以静态或单张截图声称长期性能完成。

独立使用报表 Hook 的既有调用者继续自行订阅版本，正式页面传入已接纳的版本时关闭额外订阅。显式刷新最终失败或缺少事实时仍撤下刷新前的旧值；自动通知带来的尚未就绪替代报告不自行否定原有效快照。两者以实际刷新请求版本区别，原终态失败、原事实撤销和书签撤销用例保留。
