# 原生 Part 游标按实际页保存

2026-10-11 原完整报告 `dcd9942c-dc82-4c3a-9371-b5247f6d1dbc` 创建至观测为 14,809.929 ms，内部 11,343.99 ms；原生采集为 5,059.97 ms，其中 1,849 次实际 `native.next` 为 3,679.26 ms。原生库只读人口查询为 2,848 Session、52,333 Part、13,708 Message，不删记录、不缩小历史归属候选。

原 reader 已在一页内保留当前 QueueRow 的 Part 位置，却仍对每个 Part 重复更新 TEMP queue。改为只在当前 session 的 Part EOF 和当次页冻结前，用原 SQL 将最后实际消费的 Part 位置写回。只保留一个当前游标对象，内存不会随人口增长；没有新人口上限、索引、原库写入、缓存的来源结果或查询资格变化。

所有 Part 仍依次读取、解析、计数、指纹和维护原 step/model 状态；没有跳过正文类型的 Part。字节容量不足的行仍不消费，页被冻结和原 owner ACK 的协议保持。下一页只在原 ACK 后读取 TEMP 中已经保存的位置；重放冻结页不会重复写入。Part EOF 前先保存位置再标为 parts_done，子会话发现与原队列顺序保持。保存失败沿原 catch 关闭并回滚原快照，不发该页、不补造 EOF。提前 close 与物理连接复用仍使用原清理。

独立原 scalar SQL 的字段和树事件构造完整 EOF 指纹；真实 TEMP 队列位置在每个实际页 ACK 前逐项与已消费 Part 数核对。新增回归覆盖 609 个 Part、两会话、203 个 step，三种原包大小含实际字节重试，冻结页重放、未 ACK 拒绝、提前关闭后的物理复用及真实游标 SQL 失败的原已 ACK 前缀。所有既有 native 测试及默认预算保持，新回归仅交 hosted exact-SHA CI 执行。

这是一项减少私有状态写入的候选。独立有限功能门、原静态生成配套、远端 CI、同一原库完整数据对拍和正式页面耗时仍分别验收；不能以 SQL 写入减少代签性能达标。
