# 任务全程趋势保留没有数值记录的任务

正式总览刷新验收发现，任务名册164条、趋势任务数合计112条，已记录四桶和人民币数值总和一致。原全程窗口用数值原子的存在决定任务名册和按日任务数，因而遗漏没有数值记录的任务，包括原缺口或无模型调用任务。该问题不是展示分页上限。

全程且未选择算力等维度的窗口，现在以原完整任务人口保留任务和按日身份，数值仍只合并已接纳的原用量原子；未知用量保持未知，不合成零用量或费用。任务原缺口进入对应日的质量状态。明确窗口内消耗及维度选择保持原事实选择，不能为了补齐全程人数而扩大这些人口。

按日调用及历史引用覆盖使用各任务的原身份计数，保留已有零消耗证明而不增加数值记录。没有确定所属任务的共享原生记录仍进入整体汇总和原明细，不能把原生发生日假作任务创建日来画全程趋势。实际发生时间口径保持原记录的时钟。

新报告使用 `complete-cohort-v2` 查询形状参与原 view 请求键。遇到旧、不支持完整全程人口的 view 时，以现有404原筛选恢复路径重新取得完整报告，避免旧封存行数与新页面混用。旧 view、原事实、价格、索引及投影修订不删除、不重写、不全量重建；不改变已有使用窗口或独立任务报告。该形状是派生查询兼容标识，不是任务或调用数量限制。

补充211任务的算法回归，覆盖无数值、缺口独占一天、输入超安全整数、四桶和人民币不重复累计，以及窗口/维度选择保持。补真实双引擎持久化211任务、37条展示分页到EOF、原名册与原分配器逐项对账、旧报告原筛选恢复及服务重建后的保留报告读取。生产与用例全部完成后集中验证，原失败和远端结果分别保留。
