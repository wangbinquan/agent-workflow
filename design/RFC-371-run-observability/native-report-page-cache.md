# RFC-371：统计专用原生连接的页缓存

## 问题与范围

正式页面新范围／显式刷新仍约18.4秒。原生完整读取是其中的主要耗时；当前报告内已复用物理连接，但 OpenCode 原只读连接仍使用 SQLite 默认约2 MiB的 main 页缓存。2026-10-10 原库只读 SQL 对照采用当前原 fields／JSON 资格／200 ID 传输批次，完整遍历此前1730个已EOF直接根、37113个part、40586次查询、8717个模型TEMP项。默认→64 MiB→默认的耗时分别4055.13／2188.74／3278.84ms，三个模式的全部原字段摘要均为 `7dfd4c65a13dd76f2cb37146a8d67c7d52563d98080cd080999d876b63311a1c`。这是 SQL 诊断收益，不是完整子树／协议或正式页面提速验收。

本片属于已批准的完整统计性能修复，不改变任务、调用、历史根、子树、part／step的人口或原快照、四桶、人民币及缺口。侧栏返回修复是另一独立候选；本片不代签其门或首次性能。

## 实施设计

仅在 RuntimeManagement infrastructure 的 `opencodeReportConnections.ts` 新建统计专用物理连接时，执行一次 `PRAGMA main.cache_size=-65536`。复用同一连接时不重复设置；不同generation／清理失败后新建的连接同样设置。该值是可淘汰的64 MiB数据库页面工作集预算，超过容量仍从原文件读取至EOF，不是行数、任务或调用上限，也不要求一次性分配64 MiB。

页缓存属于原报告的专用只读物理句柄，最多一个闲置句柄；原活跃reader数和完整人口均不受限制。设置不新增global pool／跨报告缓存／API／表／源库索引／公共接口。不修改物理数据、WAL、synchronous或原writer的配置。原独立reader／baseline／final入口的默认连接以及主报告数据库／PostgreSQL路径保持。每个根的原BEGIN、TEMP建表与FILE／8 MiB TEMP页缓存、逐行JSON解析时点、排序、ID批次、ACK／fingerprint／EOF、COMMIT／ROLLBACK及完整清理／finally保持。

main缓存设置是性能提示：如果原窄只读适配器拒绝该PRAGMA，只忽略此提示，继续原连接的全部读取／错误语义，不新建第二连接、不吞掉后续原BEGIN／查询／close错误。提示失败不能让已有完整统计消失或把部分人口当作EOF。源码只增加新建物理连接的窄初始化，不改原reader或字段SQL。

## 回归、实际验收与发布

保留既有连接复用文件全部原case、断言和预算，追加真实SQLite/WAL回归：检查原工厂句柄实际main缓存64 MiB、原TEMP为FILE／8 MiB；1201个原part跨多页完整四桶及fingerprint与独立原SQL oracle一致；打开原根后writer新增记录仍可写、旧根不见新值、EOF后下一次借用看到新值；原独立只读连接及writer的main配置不变、原close后句柄确实失效。追加一个只在该提示处抛错的真实适配器，之后所有原SQL实际执行，证明原完整四桶／EOF仍保持。不开模拟人口捷径。

先有限独立功能设计门，通过后实现，再有限实现门、一次必要的原canonical配套及新发布SHA hosted CI。本机不跑AW产品测试／typecheck／build／新服务／规模CI。正式已授权原服务／dev-admin页刷新同一固定范围，比较原37533条物理明细和16259个分组的全部字段、四桶／CNY／已有缺口，并实测完整生成耗时。若没有实际改善，保留诊断而不能宣称页面加速完成；所有失败和未验收范围保持。

## 正式页面实验结论与处置

2026-10-10 原 AW dev-admin 正式页面按固定完整范围执行两次产品刷新，G/H 报告首次生成分别为 18,933/19,163 ms；原 F 为 18,373 ms。本次没有证明整份报告提速。G 的全部 37,533 行与 16,259 组按原字段、原排序计算的 SHA 分别为 `f3b291c6158feae20418fe7c9f26f8997dea642c64490da70ed0235d2d3ebef6`、`e19254541a98c69f12cea23305547db06bb9b25f0c12700e2ac37aeca6779117`，均与 F 一致，四类 Token 和已知人民币估值一致。只读 SQL 诊断的改善不能替代完整报告性能验收。

该缓存提示及专用于该提示的三项追加测试不发布。主会话核对两个现场文件与封存候选完全相等后，仅逆向删除本会话的 7 行提示和 115 行测试追加；原生产 3,534 字节和原测试 16,750 字节逐字保持，未改动并行输出。v45 DESIGN/v46 SOURCE 的功能 PASS 保留为该实验的静态检视记录，不声明性能或 CI 通过。继续按原全量 EOF、逐包持久化和最终校验合同定位首次生成。
