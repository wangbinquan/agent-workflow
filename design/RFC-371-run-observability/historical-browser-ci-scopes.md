# 历史来源加入后的原浏览器断言范围

## 原失败

`c81fc950` 的 E2E 1/4 用例在打开 `A11y task observations` 时匹配三个同名入口。原 Task 列表已有 `data-observation-task`，新增历史执行入口可以合法使用同一任务名称。原 Task 行应按创建时返回的真实 Task ID 和原角色、名称共同定位；不能删除历史入口、取任意第一个同名按钮或放宽可访问性断言。

同 SHA 的 E2E 3/4 在原并行任务的 Agent ID 数组中收到额外 `null`。完整 Task 报告还包含原任务触发的历史来源。额外行可能来自记忆提取，但必须用该报告的完整原历史执行数据核实，不能先假定或直接过滤空 ID。

## 候选设计

原 E2E 完整分页、人口核对、两次模型调用、两个 Task Agent ID、费用/四桶未知资格、名称/算力查找、卡片间距、主题、移动端及键盘流程全部保持。

1. 可访问性用例保存原 `seedTerminalTask` 返回的 ID，给原精确角色/名称 locator 加上相同 Task ID 条件。
2. 并行 Task 的两 Agent ID 断言限定到实际 `purpose: task` 行，原两个 ID 和严格集合相等预言保持。其他行必须仍保留在原完整数组，并逐条证明它是 `purpose: memory`，且可匹配同 Task 的原记忆提取执行及其原 Agent 标识；若额外行实际上属于 Task Agent 或不存在对应原来源，断言继续失败。
3. 原所有已注册 runtime 的身份、修订及名称预言保持。未知注册身份行不能拿当前注册表补齐，须逐条证明它是同 Task 原历史执行中的未知运行时，且没有已受理调用、仍是未完整状态。否则仍失败。

只修复测试的具名断言范围，不改统计生产代码或来源人口。原两次失败、所有原期待值和时间预算保留。新的 hosted 精确 SHA 成功之前不声明浏览器问题已经闭合。

补充：976f590e 的总览浏览器用例在移除展示 fixture、刷新原 daemon 后也命中五个同名入口。总览与原并行任务旅程的四处页面级 Task 名称定位同样增加真实 seedTask ID 条件，保留原角色、名称、可见性、边框/背景、键盘、返回及布局预言；Agent 对话框内原具名定位保持。此次仅改 E2E，原生产 sourceDigest 不变。
