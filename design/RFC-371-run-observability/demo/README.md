# 运行观测与统计 · 交互设计原型

RFC-371 In Progress。使用合成数据、虚构模型和示例人民币费率；不是线上监控或账单。

## 打开

在仓库根目录执行（使用已安装的 Bun 和前端依赖，不安装新包）：

```sh
bun run design/RFC-371-run-observability/demo/build.ts
python3 design/RFC-371-run-observability/demo/serve.py
```

启动服务器后，在本机浏览器打开以下地址。这些是本地预览地址，远端文档站点不会运行该服务。

```text
总览：http://127.0.0.1:48371/
运行时人民币单价：http://127.0.0.1:48371/?tab=usage&settings=runtime-pricing
六 Agent 泳道：http://127.0.0.1:48371/?tab=traces&repo=all&range=24&task=RUN-0928-018
双部署对照：http://127.0.0.1:48371/?tab=deployment&deployment=crewstation&platform=ready
平台离线示例：http://127.0.0.1:48371/?tab=deployment&deployment=crewstation&platform=offline
```

端口仅绑定 loopback；服务器只暴露原型 HTML/CSS/JS 与共享 CSS，其他路径 404，不提供源码目录列表。结束预览可在启动它的终端按 Ctrl+C。

`build/` 是忽略的可重建输出；源文件在本目录。直接双击 index.html 不是支持的启动方式，需通过上述静态预览。

## 交互范围

- 部署与数据来源：独立 AW / CS 托管 AW 对照；平台正常、离线、首次快照未齐、估值迟到、模型未定价、项目未开放费用六种状态。
- 总览：时间 / 仓库 / 来源筛选、用量趋势点击到任务、Agent 消耗排行下钻。
- 任务追踪：名称或 ID 搜索、排序、任务全生命周期概览、泳道展开 / 折叠 / 缩放、关键路径强调、模型 / 工具片段详情。
- 任务内 Agent 汇总与逐次执行表；错误尝试保留用量。
- Agent 分析：跨任务汇总 → 单个任务贡献 → 全部回合与重试。
- Token 与成本：四个互斥桶、模型归因、失败 / 重试消耗、人民币定价说明；快捷进入运行时单价配置。
- 工作台设置 · 运行时：价目表、四项人民币单价、生效时间、新版本历史；嵌套共享Dialog，Esc只关最上层，关闭表单保留草稿。
- 性能与异常：完成耗时分布、异常定位、采集覆盖率。
- 明暗主题、390px 窄屏、键盘操作、CSV 导出入口（只含合成数据；文件落盘验收边界见 [计划](../plan.md)）。

原型复用仓库 `Card / TabBar / Segmented / TableViewport / Select / StatusChip / Dialog / TextInput / EmptyState / ResourceIcon` 以及完整 `styles.css`。工作台设置入口打开本原型的运行时成本管理弹窗；其他导航项是位置示意，不跳转生产页面。新增 CSS 仅用于本原型布局和图表。

## 演示边界

筛选默认按任务开始时间选择生命周期样本，图按开始时间分桶；调用级时间与模型标签为合成 fixture。没有真实数据接入、自动刷新、后台权限校验、告警通知、价格抓取、生产导出任务、生产级虚拟化与跨任务比较。

跨度缩放演示可横向滚动；实际实现的时间区间拖拽、复杂因果边、子任务 / 分片深层树和大规模虚拟化见 [技术设计](../design.md)。不以本原型的少量样本推断吞吐或采集准确性。

价格配置只保存到当前页面会话，刷新恢复示例。金额直接按人民币示例单价计算，没有汇率服务；新价待生效，既有任务仍按CNY-v1。独立运行的单价由AW维护。新增双部署页的 CS 金额是独立编写的合成平台返回值，不调用 AW 示例单价计算；模式与状态只作用于该对照页，其他页签仍演示原有同一批合成任务。首次快照未齐显示未知，离线保留示例历史并标注时间，费用隐藏或待回传时显示“—”。平台数据源与归因后端已经分批实现，真实托管 bootstrap 和正式统计页面仍未接通，原型不证明生产联动完成。
