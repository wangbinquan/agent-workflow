# RFC-371 — 泳道时间尺度与已知片段人民币估值

正式页面验收发现：28次执行尝试跨越约80分钟，几十秒的尝试在总时间轴被压为数个像素。全量报告的原始记录和耗时存在，问题在展示尺度。片段详情另有仅接受完整估值的旧条件，导致已关联的部分人民币金额被隐藏。

跨任务泳道默认以各任务在本页首个已知开始时间为零点，沿用共同秒刻度，保留同一任务的并行、先后和真实持续时间。页面明确说明这只是本页任务内对齐，不代表跨任务同时执行；“实际时间”保留原始全局时间分布。单任务页保持实际时间轴。未知、逆向、零持续和未结束区间保持原事实，开放区间仅使用报告冻结的asOf。每条尝试详情仍显示原始时间、耗时和原用量证据。

只变更前端显示坐标；完整报告的任务、调用、四桶Token、人民币金额、全量计数与无限续页机制保持。没有新增总体限制、隐藏记录、放大假条、工作流筛选、更多筛选、CSV或关注任务卡片。标准Segmented组件负责键盘与主题样式；卡片内部使用原stack/action-row间距。

片段详情直接显示已有amountDecimal（含部分估值及真实零），部分金额旁保留不完整标记；未知金额仍未知，输入／缓存读／缓存写／输出各桶分别保留未知与零。工具和子Agent不增计费用。

新增回归覆盖两个相距一小时任务的任务内偏移及并行、键盘切回实际时间、单任务旧轴、未知／逆向／零／开放边界、10001条完整显示投影，以及部分、零、完整、未定价片段金额。所有原回归、后端统计与原尺度人口不变。本机仅精确格式／lint与无断言AST；功能测试交本批精确SHA的hostedCI。正式桌面与窄屏、键盘和刷新页面另验。
