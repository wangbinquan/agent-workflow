| 发现 | 修复与回归覆盖 |
| --- | --- |
| P1：普通 starter 无数据输出时，错误码被误写成两个字符串的按位 OR | 恢复原 `data-output-required` 返回；脑图模板的 `text-output-required` 在独立分支返回。TypeScript 复查通过。 |

确认的关键合同：无决定内容的旧确认哈希保持原输入；空决定规范化为缺省；所有新增内容参与持久化、相等/归属比较和确认；状态与未知/依据等独立；复核读取当前答案、提交前刷新持久状态并核对问题集与答案，复用原接口且防止重复提交；部分锁定题只展示；两个入口根复用已选的执行绑定；self/cross 摘要与脑图停止提示完整传递决定内容。

本地仅进行限定路径格式检查、ESLint 与 TypeScript 静态核对，没有执行功能测试、E2E 或启动本地开发服务。自动化结论等待确切 SHA 的 GitHub Actions。真实模板启动、单机/托管模型追问、最终输出及任务 done、桌面和窄屏操作仍须分别记录，不以 mock binding 的标签作为真实形态证据。
