# RFC-373 实施计划

用户于 2026-10-13 审阅交互原型后批准正式实现与 commit/push；采用推荐三态方案。

1. T1：完成现有入口与样式调研、三件套、索引、功能设计门。
2. T2：实现共享编辑器布局状态、偏好解析、容器观测、三态工具栏、拖动/键盘与焦点处理。
3. T3：集中修正共享样式与旧移动端覆盖，补中英文；所有原消费者自动接入，不改保存协议。
4. T4：写齐纯函数、组件、真实页面 E2E 与原缺陷回归。T2～T4 全部完成之前只做必要的语法/格式静态自查。
5. T5：集中静态检查和功能实现门，完成后按明确路径提交并推送；以 GitHub exact-SHA CI 验证。失败先按 job/step、差异和依赖归因，只修本任务引入的问题。
6. T6：记录实际验证与未决项，再次 fetch 比较本地与远端；交接说明共同文件内容与准确 CI 状态。

验收逐项对应 proposal AC1～AC7。候选内容不变时不重复全量 gate，不对其他 session 的在制品做清理或回退。生产实现与测试默认一个功能 commit，文档结案如需要单独提交。
