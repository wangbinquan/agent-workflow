## PR 拆分建议

- PR-1：T4（`all-deny` 名实一致）——独立、低风险、可先落。
- PR-2：T1+T2+T3（业务节点受控化，含逃生阀与 golden 改形）——主体。
- PR-3：T5（网络围栏，按定档形态）。

## 风险

- **存量工作流破坏**（最高）：T2/T3 的默认策略直接决定影响面，故 T0a 必须先定。
- **golden 大面积改形**：只允许"改形不删项"，且需逐条对照映射表说明减少的工具面。
- **smoke 诊断力下降**：T4 若使 smoke 无法区分三态，则回退。
- 并行 RFC-239/240/241 活跃：本 RFC 触及 `runtime/claudeCode/*` 与 `runtime/types.ts`，
  实施前重读，按路径精确提交。
